# ログイン・端末間同期のセットアップ(Firebase)

スマホでもパソコンでも同じ受講生プランを見たり編集したりできるようにするための設定です。
サービスは Google の [Firebase](https://firebase.google.com)(無料の Spark プランで使えます)を使います。**所要時間は10〜15分**です。

設定をしないあいだは、ログイン機能は画面に出ず、これまでどおり端末内だけで動きます。

> Firebase の管理画面の名称・配置は、変わることがあります。見つからない場合は、近い名前の項目を探してください。無料枠の数字も目安です(最新の内容は Firebase の料金ページで確認してください)。

> すでに別のアプリで Firebase を使っている場合は、**そのプロジェクトを使い回さず、このアプリ用に新しいプロジェクトを作る**ことをおすすめします。
> ルール(手順3)を上書きして、既存のアプリが動かなくなる事故を防げます。使い回す場合の注意は、手順3に書いています。

## 1. プロジェクトとウェブアプリを作る

1. https://console.firebase.google.com を開き、「プロジェクトを追加」を押します。
   - プロジェクト名: 例 `lifeplan`(Google アナリティクスは「無効」で構いません)
2. 作成後、プロジェクトのトップで **「ウェブ」アイコン(`</>`)** を押して、ウェブアプリを登録します。
   - アプリのニックネーム: 例 `lifeplan-web`(「Firebase Hosting」にはチェック不要)
3. 表示される設定(`firebaseConfig`)のうち、次の2つを控えます。
   - `apiKey` … `AIzaSy...`
   - `projectId` … `lifeplan-xxxxx`

## 2. ログインを有効にする

1. 左メニューの **構築 → Authentication** →「始める」を押します。
2. **Sign-in method(ログイン方法)** で **「メール / パスワード」** を有効にして保存します(「メールリンク」は不要です)。
3. **設定 → 承認済みドメイン** に、公開しているアプリのドメイン `yusukeokane2024-stack.github.io` があることを確認します(なければ追加)。

## 3. データベース(Firestore)とルールを設定する

1. 左メニューの **構築 → Firestore Database** →「データベースを作成」を押します。
   - ロケーション: `asia-northeast1`(東京)がおすすめ(あとから変更できません)
   - モード: **本番環境モード**(あとでルールを設定します)
2. **ルール** タブを開き、このリポジトリの [`firebase/firestore.rules`](../firebase/firestore.rules) の中身をすべて貼り付けて「公開」を押します。
   - これで、**本人以外は自分のプランを読み書きできない**設定になります。
   - ⚠️ 既存のアプリと同じプロジェクトを使う場合は、**既存のルールを消さず**、`match /lifeplanUsers/{uid} { ... }` の部分だけを、既存の `match /databases/{database}/documents { ... }` の中に追加してください。

## 4. URLとキーをアプリに設定する

[`config.js`](../config.js) に、手順1で控えた2つを貼り付けて、コミット・公開します。

```js
window.LIFEPLAN_CONFIG = window.LIFEPLAN_CONFIG || {
  firebaseApiKey: "AIzaSy...",
  firebaseProjectId: "lifeplan-xxxxx",
};
```

> Firebase の `apiKey` は、パスワードのような秘密の値ではなく、ブラウザに置く前提の識別用の値です。公開しても構いません。
> データを守っているのは手順3のルールです。**ルールを「テストモード」(誰でも読み書き可)のままにしないでください。**

## 5. 動作確認

1. 公開したアプリを開くと、画面上部に **「☁️ ログイン」** ボタンが出ます。
2. メールアドレスとパスワードで「新規登録」→ ログインします。
3. 別の端末(スマホ ⇄ パソコン)で同じアカウントにログインして、受講生プランが表示されることを確認します。
4. Firebase の Firestore Database を開くと、`lifeplanUsers` の中にデータができています。

## 使い方のポイント

- **自動で同期**: 入力すると約2秒後にサーバーへ保存されます。アプリを開いたとき・画面に戻ったとき・オンラインに戻ったときにも、他の端末の変更を取り込みます。
- **オフラインでも使えます**: 同期できなかった変更は端末に残り、通信が戻ると自動で送られます。
- **読み取り回数を抑えています**: 変更がないときは、1回の確認だけで終わります(Firestore の無料枠は、1日あたり読み取り5万回・書き込み2万回まで)。
- **同じプランを2台で同時に編集して食い違った場合**: 新しい方を残し、古い方は「(競合コピー)」という別のプランとして残します(内容は失われません)。
- **ログアウト**: 共有の端末では「この端末のプランも削除する」を選んでください(アカウントにはデータが残るので、再ログインで復元できます)。
- **パスワードを忘れたとき**: ログイン画面の「パスワードを忘れた場合」を押すと、Firebase から再設定のメールが届きます。メールのリンクで新しいパスワードを設定してから、アプリでログインしてください。

## 知っておいてほしいこと

- プランの内容(年収・資産など)は、Firestore に保存されます(通信と保存は Google により暗号化されますが、**アプリ側ではさらに暗号化していません**)。プロジェクトの管理者(あなた)は、Firebase の管理画面から全アカウントのデータを見ることができます。受講生の個人情報を扱う場合は、**利用目的の説明と同意**を取り、利用規約・プライバシーポリシーを用意してください。
- **新規登録は、誰でもできる状態**です(アプリのURLを知っている人は、アカウントを作れます)。受講生以外に使わせたくない場合は、人数分のアカウントを作り終えたあとに、Authentication の **設定 → ユーザーのアクション** で「作成(登録)を有効にする」をオフにしてください(このとき、ログインはそのまま使えます)。
- **1つのアカウント = 1人の講師(または1人の利用者)** の想定です。受講生本人が自分のアカウントを作って使うことも、講師が1つのアカウントで受講生全員のプランを管理することもできます。
- 無料の Spark プランでは、使いすぎても勝手に課金されることはありません(上限を超えると、その日は読み書きが止まります)。有料の Blaze プランに変更しない限り、請求は発生しません。
