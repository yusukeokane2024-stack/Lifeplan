# ログイン・端末間同期のセットアップ(Supabase)

スマホでもパソコンでも同じ受講生プランを見たり編集したりできるようにするための設定です。
サービスは [Supabase](https://supabase.com)(無料プランあり)を使います。**所要時間は10〜15分**です。

設定をしないあいだは、ログイン機能は画面に出ず、これまでどおり端末内だけで動きます。

## 1. プロジェクトを作る

1. https://supabase.com でアカウントを作り、「New project」を作成します。
   - Project name: 例 `lifeplan`
   - Database Password: 強いパスワード(控えておく。アプリでは使いません)
   - Region: `Northeast Asia (Tokyo)` がおすすめ
2. プロジェクトの準備ができるまで数分待ちます。

## 2. テーブルを作る

1. 左メニューの **SQL Editor** → 「New query」を開きます。
2. このリポジトリの [`supabase/schema.sql`](../supabase/schema.sql) の中身をすべて貼り付けて **Run** を押します。
3. 「Success」と出れば完了です。`plans` というテーブルができ、**本人以外は読み書きできない設定(RLS)** が有効になります。
   - Table Editor で `plans` を開き、「RLS enabled」になっていることを確認してください。

## 3. ログインの設定をする

左メニューの **Authentication** で次を設定します。

1. **Sign In / Providers → Email** が有効(Enabled)であることを確認します。
2. **Confirm email(メール確認)** をどうするか決めます。
   - **オフ(おすすめ・少人数向け)**: 登録するとすぐログインできます。
   - **オン**: 登録時に確認メールが届き、リンクを開くまでログインできません。Supabase 標準のメール送信は**送信数の上限がとても少ない**(1時間あたり数通)ため、人数が多い場合は独自のSMTP設定が必要です。
3. **URL Configuration** を設定します(パスワード再設定メールのリンク先になります)。
   - **Site URL**: `https://yusukeokane2024-stack.github.io/Lifeplan/`
   - **Redirect URLs**: 同じURLを追加

## 4. URLとキーをアプリに設定する

1. 左メニューの **Project Settings → API**(または「Data API」/「API Keys」)を開きます。
2. 次の2つをコピーします。
   - **Project URL** … `https://xxxxxxxxxxxx.supabase.co`
   - **anon public**(または **Publishable**)キー
3. [`config.js`](../config.js) の2か所に貼り付けて、コミット・公開します。

```js
window.LIFEPLAN_CONFIG = window.LIFEPLAN_CONFIG || {
  supabaseUrl: "https://xxxxxxxxxxxx.supabase.co",
  supabaseAnonKey: "eyJhbGciOi...(または sb_publishable_...)",
};
```

> ⚠️ **`service_role` キー(または `secret` キー)は絶対に入れないでください。** これは全データを読み書きできる管理者用のキーです。
> `anon` / `publishable` キーは、ブラウザに置く前提のキーで、公開しても構いません(データは手順2のRLSで守られます)。

## 5. 動作確認

1. 公開したアプリを開くと、画面上部に **「☁️ ログイン」** ボタンが出ます。
2. メールアドレスとパスワードで「新規登録」→ ログインします。
3. 別の端末(スマホ ⇄ パソコン)で同じアカウントにログインして、受講生プランが表示されることを確認します。

## 使い方のポイント

- **自動で同期**: 入力すると約2秒後にサーバーへ保存されます。アプリを開いたとき・画面に戻ったとき・オンラインに戻ったときにも、他の端末の変更を取り込みます。
- **オフラインでも使えます**: 同期できなかった変更は端末に残り、通信が戻ると自動で送られます。
- **同じプランを2台で同時に編集して食い違った場合**: 新しい方を残し、古い方は「(競合コピー)」という別のプランとして残します(内容は失われません)。
- **ログアウト**: 共有の端末では「この端末のプランも削除する」を選んでください(アカウントにはデータが残るので、再ログインで復元できます)。
- **別のアカウントでログイン**: 端末に残っている前のアカウントのプランは、確認のうえ削除してから読み込みます(混ざりません)。

## 知っておいてほしいこと

- プランの内容(年収・資産など)は、Supabase のデータベースに**暗号化されない状態で**保存されます(通信は暗号化されます)。プロジェクトの管理者(あなた)は、Supabase の管理画面から全アカウントのデータを見ることができます。受講生の個人情報を扱う場合は、**利用目的の説明と同意**を取り、利用規約・プライバシーポリシーを用意してください。
- **1つのアカウント = 1人の講師(または1人の利用者)** の想定です。受講生本人が自分のアカウントを作って使うことも、講師が1つのアカウントで受講生全員のプランを管理することもできます。
- 無料プランでは、**1週間ほどアクセスがないとプロジェクトが一時停止**されることがあります(管理画面から再開できます)。利用を続けるなら有料プランも検討してください。
- パスワードを忘れた場合は、ログイン画面の「パスワードを忘れた場合」からメールで再設定できます(手順3のURL設定が必要です)。
